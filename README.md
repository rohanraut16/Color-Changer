# Color Changer

A simple and interactive color changer web app built using HTML, CSS, and JavaScript.
Users can generate random colors or choose their own custom color instantly.

## Features

* Random color generator
* Custom color picker
* Live background color change
* Current color code display
* Responsive and clean UI

## Concepts Used

* DOM Manipulation
* Event Handling
* Random Color Generation
* JavaScript Functions

## Example Colors

* `red`
* `blue`
* `tomato`
* `#f4f4f4`

## Technologies Used

* HTML
* CSS
* JavaScript
